# Maël Jullien — Personal Portfolio

Personal portfolio and research archive built with Next.js, React, and CSS.

## Run locally

Requires Node.js 22 or newer.

```bash
npm ci
npm run dev
```

## Deploy

The site uses Next.js static export. Every push to `main` builds and deploys
the `out` directory to GitHub Pages through
`.github/workflows/deploy-pages.yml`.
